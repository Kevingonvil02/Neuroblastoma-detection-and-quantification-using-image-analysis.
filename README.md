
## Proyecto Medición de neuroblastoma en peces cebra - Kevin Alejandro Gonzalez Villanueva ##
Una de las tareas más importantes que la visión por computador es la de resolver el problema de detección. En este notebook abordaremos la detección de neuroblastoma, un tumor maligno prevalente en la población pediátrica que puede ser detectado y analizado mediante la visión por computador en un modelo in vivo de peces cebra. Es así que para abordar el problema de detección de neuroblastoma se usarán técnicas como operaciones morfológicas, técnicas de umbralización y segmentación que a posteriori podrán otorgar datos necesarios en la implementación de un entorno que entrene una red neuronal mediante el mecanismo de aprendizaje supervisado. En el archivo .ipynb se encuentra todo descrito e implementado, sin embargo el dataset tendrá que ser descargado y utilizado como carpeta main. Además, el archivo .ipynb estará en el archivo .zip adjunto y descargable.
